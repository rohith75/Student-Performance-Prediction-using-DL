# Student Performance Prediction Using Deep Learning

## Project
Predict a student's final score from attendance, study hours, previous marks, assignments, sleep, class participation and other factors.

## Files
- `student_performance_dataset.csv` - 5,000-row dataset
- `Student_Performance_Prediction.ipynb` - training and evaluation notebook
- `app.py` - Streamlit web application
- `requirements.txt` - Python packages

## Run
1. Open the notebook in Jupyter.
2. Run all cells to train and save:
   - `student_performance_model.keras`
   - `preprocessor.pkl`
3. From the same folder run:
   `streamlit run app.py`
